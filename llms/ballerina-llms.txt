# Ballerina

> Ballerina is an open-source programming language for the cloud, built by WSO2, whose type
> system, syntax and tooling are designed around network interaction: services, clients, data
> transformation and integration are language constructs rather than framework add-ons. Its
> package registry, Ballerina Central, exposes a public read API — the only HTTP API Ballerina
> operates — and its agent surface is a CLI plus a stdio MCP server, not a hosted endpoint.

Generated by API Evangelist on 2026-09-04 from this provider record. Ballerina does not publish
its own /llms.txt (https://ballerina.io/llms.txt returned 404 on 2026-09-04). Every URL below
was fetched and returned HTTP 200 unless noted.

## API

- [Ballerina Central API](https://api.central.ballerina.io): Public, unauthenticated read API
  for the package registry. Six operations, all GET: search/list packages, full-text package
  search, list a package's published versions, search connectors, search triggers, and fetch
  the generated API documentation model for a package version. No API key, no OAuth, no
  published rate limits, no rate-limit response headers.
- [OpenAPI (probed)](https://raw.githubusercontent.com/api-evangelist/ballerina/refs/heads/main/openapi/_original/ballerina-central-api.yml):
  Written from live calls to every operation on 2026-09-04 and cross-checked against WSO2's own
  clients of the API. Ballerina publishes no OpenAPI of its own for this surface.

Key operations:
- GET /2.0/registry/packages?q=&org=&limit=&offset=&readme= — list or search packages
- GET /2.0/registry/search-packages?q= — full-text search with suggestions and highlighting
- GET /2.0/registry/packages/{org}/{name} — version strings, newest first
- GET /2.0/registry/connectors?q= — connector clients declared by published packages
- GET /2.0/registry/triggers?q= — event triggers/listeners declared by published packages
- GET /2.0/docs/{org}/{name}/{version} — full generated documentation model for one version

## Agent surface

- [ballerina-library MCP server](https://github.com/ballerina-platform/skills): First-party,
  stdio, v0.4.0. One tool, `get_library`, returning a package's full API as a compact syntax
  string. Installed as a Claude Code plugin; there is no hosted MCP endpoint.
- [Ballerina Agent Skills](https://github.com/ballerina-platform/skills): Four first-party
  SKILL.md skills across two plugins — `ballerina` (write/run/test/deploy Ballerina code) and
  `ballerina-libdev` (generating-connectors, generate-connector-docs,
  making-graalvm-compatible).
- No A2A agent card is served on any Ballerina host (probed 2026-09-04).

- [Ballerina Library](https://lib.ballerina.io/): Generated API docs for every published package.
- [Ballerina Central](https://central.ballerina.io/): Package registry front end.
- [Downloads](https://ballerina.io/downloads/): Installers; current GA 2201.13.5 (2026-07-27).
- [Publish to Central](https://ballerina.io/learn/publish-packages-to-ballerina-central/):
  Access token in ~/.ballerina/Settings.toml under [central] accesstoken, or
  BALLERINA_CENTRAL_ACCESS_TOKEN; tokens expire after one year.
